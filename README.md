# Luxury Interactive Wedding Invitation — Sofia S Nair & Akhil RV 🌸💍

An interactive, romantic, mobile-first wedding invitation web application built with **React 19**, **TypeScript**, **Vite**, **Tailwind CSS**, **Lucide Icons**, **Web Audio API**, and **HTML5 Canvas**.

---

## ✨ Key Features & Aesthetic

- **Theme & Aesthetic**: *"Dusty Rose, Blush Pink & Vintage English Garden Floral"* (`#FDF8F7`, `#FFFBF9`, `#B87D89`, `#5C3843`, `#C9A875`).
- **3D Wax Seal & Envelope Entrance**: Interactive tactile envelope with wax seal sound physics. The rest of the invitation is revealed only when broken.
- **Falling Rose Petals Canvas**: Physics-driven floating blush rose petals with wind speed and pause controls.
- **Acoustic Harp Serenade**: In-browser synthesized acoustic harp arpeggio serenade with animated rose-gold waveform visualizer.
- **Wedding Card with Couple Portrait**: Features a clean cutout portrait of Sofia & Akhil embedded within a Victorian gilded arch, complete with parent details (`D/o. Shylendran Nair & Ajitha S Nair` & `S/o. Rajan T & Valsala`).
- **Interactive Event Itinerary**:
  - **Reception**: Wednesday, 11 November 2026 at 6:30 PM (Mithila Auditorium, Attingal).
  - **Wedding Ceremony**: Thursday, 12 November 2026 (Muhurtham 10:30 AM – 11:15 AM) at Udaya Palace Convention Centre, Kowdiar, Trivandrum.
- **Dual Location & Calendar Hub**: Interactive Google Maps embeds and 1-tap **Add to Calendar** (.ICS export for Google Calendar, Apple Calendar, Outlook).
- **Google Forms RSVP Integration**: Embedded official Google Form with fullscreen modal launcher and WhatsApp confirmation.
- **High-Res Original Card Lightbox**: Full-resolution zoomable viewer for the printed physical invitation card.

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite 8](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Celebration Effects**: [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
- **Audio Engine**: Native Web Audio API (tactile seal snap + acoustic harp synthesis)

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or pnpm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/kebinbjacob/sofia-wedding-invitation.git

# Navigate to project directory
cd sofia-wedding-invitation

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
